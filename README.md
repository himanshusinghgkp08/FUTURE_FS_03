☕ The Daily Grind | Local Business Project
This is a professional, responsive landing page developed for a local cafe to enhance its digital presence and customer engagement. This project was completed as part of the Full Stack Web Development – Task 3 (2026) internship by Future Interns.

✨ Features

Dynamic Menu Rendering: Uses Vanilla JavaScript to inject menu categories (Hot/Cold Drinks, Snacks, Desserts) from a data object for easy maintenance.

Interactive Ordering System: Features a custom modal pop-up for order simulation, improving user conversion rates.

Glassmorphism UI: Modern navigation design using backdrop-filter and Tailwind CSS for a premium aesthetic.

Responsive & Accessible: Fully optimized for mobile and desktop views with a smooth scroll experience.

🛠️ Tech Stack
Frontend: HTML5,JavaScript, Tailwind CSS.

Interactivity: Vanilla JavaScript (DOM Manipulation & Event Handling).

Design: Google Fonts (Playfair Display & Inter), Font Awesome Icons.

🚀 Business Impact (The Pitch)

As a Computer Science student with a focus on Software Engineering, I designed this solution to solve real-world business problems:

Professionalism: Replaces dated or non-existent web presence with a high-end "Artisan" brand identity.

Trust & Retention: Integrated Google Maps and an "Our Story" section to build community trust and drive foot traffic.

Efficiency: Provides a clear, categorized digital menu that reduces customer inquiry time.
